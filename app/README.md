# FastAPI & Stripe Payment Engine

A robust backend payment service built with **FastAPI**, **SQLModel (PostgreSQL/SQLite)**, and **Stripe Checkout**, designed to integrate seamlessly with enterprise automation platforms like **Workato**.

## Features
- Secure Stripe Checkout Session generation
- Verified webhook listener for asynchronous payment tracking
- Relational database state management using SQLModel
- Automated testing suite with Pytest
